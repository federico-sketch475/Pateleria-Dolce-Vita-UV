Información técnica

Documentación del proyecto web y justificación de las decisiones tomadas durante su desarrollo.

01

Estructura semántica HTML5

El sitio utiliza etiquetas semánticas de HTML5 para organizar correctamente el contenido y facilitar su comprensión.

<header>

Se utiliza en la parte superior de la página para contener la identidad de Dolce Vita y la navegación principal.

<nav>

Contiene los enlaces de navegación que permiten desplazarse entre las distintas secciones de la One-Page.

<main>

Contiene el contenido principal de la página, diferenciándolo de la navegación y del pie de página.

<section>

Divide el contenido en bloques temáticos: inicio, historia, especialidades, experiencia, italiano y contacto.

<article>

Se utiliza para contenidos independientes, como las tarjetas de productos, etapas de trabajo e información histórica.

<footer>

Contiene información final del sitio, enlaces secundarios y los datos del proyecto.

02

CSS y diseño visual

El diseño se realizó mediante CSS3, utilizando diferentes herramientas para conseguir una interfaz moderna, responsive e interactiva.

CSS

Se utiliza una hoja de estilos externa llamada style.css.

Flexbox

Se utiliza para organizar elementos como la navegación, botones, información de contacto y diferentes componentes.

CSS Grid

Se utiliza para crear estructuras de columnas, como las tarjetas de productos y la sección de contacto.

Media Queries

Permiten adaptar el sitio a celulares, tablets y computadoras mediante diferentes tamaños de pantalla.

Variables CSS

Se utilizan variables para mantener organizados colores, fondos, bordes, sombras y otros valores del diseño.

Animaciones

Se incorporaron transiciones, efectos hover y animaciones de aparición para mejorar la experiencia del usuario.

03

JavaScript e interactividad

JavaScript permite que diferentes elementos del sitio reaccionen a las acciones del usuario.

  • Cambio entre modo claro y modo oscuro.
  • Menú responsive para dispositivos móviles.
  • Indicador de sección activa en la navegación.
  • Ventana modal para consultar información de los productos.
  • Botones para mostrar y ocultar información.
  • Formulario interactivo de consultas.
  • Animaciones al desplazarse por la página.
04

Arquitectura One-Page

Se decidió utilizar una arquitectura One-Page para presentar toda la información principal de Dolce Vita dentro de una única página.

La navegación utiliza enlaces internos mediante identificadores, permitiendo que el usuario pueda desplazarse rápidamente entre las diferentes secciones.

Esta estructura resulta adecuada para una pastelería porque permite mostrar la identidad, historia, productos, experiencia y contacto sin obligar al usuario a cambiar constantemente de página.

05

Recursos externos

El sitio utiliza recursos externos para mejorar la presentación visual.

  • Google Fonts para las tipografías.
  • Imágenes externas utilizadas como fotografías de referencia de productos.
  • HTML, CSS y JavaScript como tecnologías principales del proyecto.
06

Identidad bilingüe

El sitio combina español e italiano para reforzar la identidad de la marca y relacionarla con la tradición de la pastelería italiana.

Los nombres de algunos productos, títulos y expresiones utilizan italiano, mientras que la información principal permanece en español para facilitar la comprensión del usuario.

07

Experiencia de usuario

Se buscó que los elementos que parecen botones realmente tengan una función.

  • Los botones de productos abren información adicional.
  • Los llamados a realizar pedidos llevan al formulario de contacto.
  • El menú permite desplazarse entre las secciones.
  • El botón de tema cambia el aspecto visual.
  • El formulario permite realizar una consulta de manera interactiva.
